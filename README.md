## ✨ Design & Content Updates Applied

### 1. 🎨 Luxurious Blush Rose, Gold & Ivory Palette
- Carefully calibrated warm tones: **Blush Rose (`#FCECEE`, `#D97786`), Metallic Rich Gold (`#C5A059`, `#DFc27D`), and Ivory (`#FFFDF9`, `#FAF6F0`)**.
- **High-Contrast Readability:** Enforced rich dark text (**Deep Burgundy `#4A0E17`** and **Charcoal `#2C2C2C`**) across all light backgrounds for crystal-clear visibility on mobile viewports.

### 2. 🌓 Day and Night Mode Toggle
- Fixed, elegant floating toggle switch (sun/moon icon) on the top-left of the viewport.
- Seamlessly switches between:
  - **Day Mode:** Warm Blush Rose, Gold, and Ivory with Deep Burgundy & Charcoal high-contrast typography.
  - **Night Mode:** Moody Midnight Burgundy background (`#140407` / `#1D070D`) with luminous warm gold accents and crisp light typography (`#FFF5ED`, `#FDE8D7`).
- Automatically remembers the user's preference in `localStorage`.

### 3. 💌 Refined Realistic Envelope Opener
- Clean, realistic luxury wedding stationery envelope in Blush Rose and Champagne Gold with 3D folding perspective.
- Monogram wax seal marked **N & N** (Dr. Naveen Kumar & Dr. Niranjana).
- **Religious Invocations Removed:** Completely secular, romantic, and dignified wording.
- Tap anywhere on the cover screen or envelope to open with celebratory confetti and rose petals.

### 4. 🖼️ Elegant Gold-Bordered Photographic Frame (Hero Section)
- Replaced cartoon character illustrations with a gallery-grade, gold-bordered photographic placeholder frame.

## 🚀 How to Run Locally

Open `index.html` directly in any web browser (Chrome, Edge, Safari, Firefox), or run a local static server:

```bash
# Using Node.js
npx serve .

# Or using Python
python -m http.server 8080
```
